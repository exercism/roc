# Instructions Append

## Operator syntax

The arithmetic functions support regular function calls, static dispatch (a.k.a., method call syntax), and operators:

| Function call | Method call | Operator |
| --- | --- | --- |
| `plus(z1, z2)` | `z1.plus(z2)` | `z1 + z2` |
| `minus(z1, z2)` | `z1.minus(z2)` | `z1 - z2` |
| `times(z1, z2)` | `z1.times(z2)` | `z1 * z2` |
| `div_by(z1, z2)` | `z1.div_by(z2)` | `z1 / z2` |
