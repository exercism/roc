# Instructions Append

Looking for a place to start? Here are a few things you might want to tidy up:

- One function does everything
- Duplicated logic and repeated work
- Deep nesting
- Cryptic names
- Scattered formatting rules
- Unexplained constants
- Unnecessary mutable state
- Implicit enum fallbacks
- Helpers with unrelated responsibilities
- Empty strings standing in for errors

Pick whatever catches your eye, and keep the tests green!
