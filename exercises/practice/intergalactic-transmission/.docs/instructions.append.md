## Hints

<details>
<summary>Show hints</summary>

Roc's integer functions include `bitwise_and`, `bitwise_or`, `shl_wrap`, and `shr_wrap`.
You can call them with method syntax, such as `byte.bitwise_and(0b11111110)`.
With `U8` values, left shifts can discard bits outside the byte, so keep any bits you still need before shifting.
