# Instructions Append

## The `roc-isodate` package

The [`roc-isodate` package](https://github.com/ageron/roc-isodate) is available in the header of `gigasecond-test.roc` (with alias `isodate`).
This package is a (temporary) fork of [the package by @imclerran](https://github.com/imclerran/roc-isodate).
You can use it in your solution if you want, for example by importing `isodate.DateTime`.
